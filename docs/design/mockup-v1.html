📐 关键改动 vs 当前实现

  1. 主色 #2563eb → #4f46e5（Indigo）— 减少蓝色饱和度，更像专业开发工具
  2. 行高 28 → 26px — 单屏多 8% 行数，长列表更经济
  3. 列表字体 ui-monospace → JetBrains Mono — 数字字符宽度恒定、可读性更好
  4. Logo + 标题区 — 当前裸标题，加 5×5 实心方块 logo 视觉锚点
  5. Level chip 配色 — 当前 bg-blue-200 / text-blue-800 偏强；改为 bg-blue-100 / text-blue-700 更柔和
  6. Sparkline 时间轴字号 — 9px 灰色，明确"参考用"，不与数据竞争
  7. 选中行 — 当前 bg-blue-50；改为 bg-indigo-50 + 2px 左侧 indigo border，定位更明确
  8. Drawer 头部按钮 — ↑/↓ 用 ctl-icon 紧凑变体（28×28 方形）
  9. Footer 状态栏 — 加 mono 字体的 cache hit / latency 显示（最右侧），传达"快"的感觉
  10. Empty state / Loading state — 设计稿暂未画，后续补
