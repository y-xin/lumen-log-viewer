设计说明

视觉锚点
iTerm2 / Warp / Sublime Merge / Honeycomb / k9s — terminal native 美学
字体
JetBrains Mono 全场（包括 chrome）— 等宽即风格，无需 sans 切换
色板
BG #0a0e14 (主) / #0f141b (次) / #151b24 (浮) — 三级 surface 层级清晰，无阴影
主色
cyan #22d3ee — terminal accent 经典；不用 blue/indigo 因为太"app"
level
仅 dot 前缀 + 文字着色，无 bg chip — 减少色块视觉噪声
行高
24px (-4)，11.5px 字号 — 单屏多 14% 行数
圆角
3px (ctl) / 0px (modal) — terminal 风格更方
footer
命令行 prompt 风格 matched 12,847 — 强化"工具感"

vs 当前实现：彻底换皮，不是微调

  • · 主体配色从浅 → 深，几乎所有 surface 颜色重写
  • · 字体从 system sans → JetBrains Mono 全场
  • · level chip 从 bg-color → dot + text-color，去除色块
  • · 控件 hover 从 slate-50 → bg-2 + cyan 边框
  • · footer 从普通文本 → terminal prompt 风格
  • · drawer 从白底阴影 → 深底 + 1px cyan-dim 左边框 + 黑色 outer shadow
  • · Sparkline 从堆叠 area → 细线 stroke (无填充)，避免色块在暗底过重
  • · 标题 chrome 加 log/viewer 文本（无显式 logo 文字）— 路径式命名

如果走这条路，还可以做：

  • · 列表行 hover 时左侧出现 › 指针（鼠标位置）
  • · 行末状态字段（如 HTTP 200/401）按值自动 colorize（cyan = 2xx，warn = 4xx，error = 5xx）
  • · tab title 显示 ● main.log · 12.8k matched（带状态点）
  • · 加 vim-style : 命令面板（可选）
